# Spec 0089 — Clippy grün unter Windows (aufgelöst)

Status: aufgelöst
Nachfolger: Spec 0090 (§2, A9, A10), ADR 0122 (R1)

Eine Aufgabenliste, um die CI unter Windows über Clippy hinaus zu bringen.
Dass die CI auf allen drei Betriebssystemen dieselben Prüfungen fährt,
steht in Spec 0090; wie Tests mit Unix-Schnittstellen gekennzeichnet
werden, in ADR 0122.
