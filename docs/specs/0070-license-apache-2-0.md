# Spec 0070 — Lizenzwechsel auf Apache License 2.0 (aufgelöst)

Status: aufgelöst
Zweck: Der Wechsel der Projektlizenz auf Apache License 2.0; die heutige Lizenz steht in Spec 0099.
Nachfolger: Spec 0099 (§1, Projektlizenz), ADR 0060

Die Projektlizenz ist in Spec 0099 beschrieben; Gründe und Folgen des
Wechsels von FSL-1.1-MIT auf Apache-2.0 stehen in ADR 0060.

Mit Version 0.8.0 wechselt die Projektlizenz auf GPL-3.0-only (ADR 0163).
