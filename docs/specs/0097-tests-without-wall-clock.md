# Spec 0097 — Tests ohne Wanduhr (aufgelöst)

Status: aufgelöst
Nachfolger: ADR 0122 (R6–R9 und Nachweis), Spec 0090 (§2, A9)

Eine Aufgabenliste für Tests, die auf echte Zeit statt auf ein Ereignis
warteten. Die Regeln dafür stehen in ADR 0122. Dass die CI den Workspace
auch ohne Test-Features baut, steht in Spec 0090.
