# Spec 0091 — Tests grün unter Windows (aufgelöst)

Status: aufgelöst
Nachfolger: Spec 0075 (§3.1.4, `Include`), Spec 0090 (§2, A9), ADR 0122
(R2, R3)

Das einzige Produktverhalten dieser Spec — ob ein `Include` ein Muster
ist, entscheidet allein der geschriebene Wert — steht jetzt in Spec 0075.
Dass der Testschritt der CI alle scheiternden Ziele zeigt, steht in
Spec 0090; die Regeln für plattformabhängige Tests in ADR 0122.
