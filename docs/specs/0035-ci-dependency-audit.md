# Spec 0035 — CI: Dependency-Audit und Lizenzprüfung (aufgelöst)

Status: aufgelöst
Nachfolger: Spec 0090 (§3, A2–A4, A12, A13), ADR 0028, ADR 0083

Die Prüfung der Rust-Abhängigkeiten auf Sicherheitslücken, erlaubte
Lizenzen und Herkunft ist in Spec 0090 beschrieben. Die frühere
Einführung im Berichtsmodus ist abgeschlossen; die Prüfungen blockieren.
