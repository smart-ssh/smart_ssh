# Spec 0041 — macOS-Signierung in einer separaten Release-Pipeline (aufgelöst)

Status: aufgelöst
Nachfolger: Spec 0090 (§5, Grenzen), ADR 0022, ADR 0033

Diese Spec war die Vorbereitung einer Release-Pipeline außerhalb dieses
Repositorys und beschrieb kein Verhalten dieses Repositorys. Release-Pakete
aus diesem Repository werden weder signiert noch notarisiert (Spec 0090,
§5). Die lokale Entwicklungssignatur steht in ADR 0022.
