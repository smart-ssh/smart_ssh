# Spec 0083 — Anwendungs-Hülle in Module aufteilen (aufgelöst)

Status: aufgelöst
Nachfolger: ADR 0076, `docs/architecture.md`, Spec 0084

Diese Spec war ein reiner Umbauauftrag (zwei sehr große Dateien in
thematische Module zerlegen, ohne Verhaltensänderung) und beschrieb kein
Produktverhalten. Der Schnitt und seine Begründung stehen in ADR 0076, die
heutige Aufteilung der Crates in `docs/architecture.md` und Spec 0084.
Verweise im Code auf „Spec 0083" meinen diesen abgeschlossenen Umbau.
