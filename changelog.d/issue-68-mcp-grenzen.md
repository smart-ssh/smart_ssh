### Sicherheit
- Externe Tools (MCP) können je Server höchstens 4 eigene Sitzungen offen
  halten. Eine weitere Anfrage bekommt eine Fehlermeldung und öffnet weder
  Verbindung noch Tab, bis ein MCP-Tab dieses Servers geschlossen wird. Der
  Name eines Tools wird in Tab und Benachrichtigung auf 64 Zeichen gekürzt.
