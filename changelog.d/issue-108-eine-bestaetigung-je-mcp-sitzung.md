### Sicherheit
- In einer MCP-Sitzung wartet höchstens eine Aktion zugleich auf Bestätigung. Jede weitere vorgeschlagene Aktion wird sofort mit einem Fehler abgewiesen, der auf die offene Bestätigung in der App verweist; so bleibt der Tab-Hinweis korrekt und das Schließen des Tabs lehnt die offene Aktion zuverlässig ab.
